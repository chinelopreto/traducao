# Dragon's Dogma Online - Tradução

Este repositório contém arquivos de tradução para Dragon's Dogma Online (DDON), um MMORPG desenvolvido pela Capcom.

## Conteúdo

- **gmd.csv**: Traduções do japonês para o português
- **gmd1.csv**: Traduções do japonês para o inglês

## Sobre os Arquivos

Os arquivos CSV contêm dados de tradução extraídos do jogo, incluindo:
- Conquistas (Achievements)
- Nomes de habilidades e magias
- Descrições de itens
- Textos da interface do usuário
- Diálogos e mensagens do jogo

### Estrutura dos Arquivos CSV

Cada arquivo CSV contém as seguintes colunas:
- **Index**: Índice do item
- **Key**: Chave identificadora no jogo
- **MsgJp**: Texto original em japonês
- **MsgEn/MsgPt**: Texto traduzido
- **GmdPath**: Caminho do arquivo GMD no jogo
- **ArcPath**: Caminho do arquivo ARC
- **ArcName**: Nome do arquivo ARC
- **ReadIndex**: Índice de leitura

## Como Usar

1. Os arquivos podem ser usados para modding do jogo
2. As traduções podem ser importadas para ferramentas de tradução
3. Útil para referência de termos e nomenclaturas do jogo

## Contribuições

Contribuições para melhorar as traduções são bem-vindas. Por favor, mantenha a consistência terminológica e a qualidade das traduções.

## Nota

Este projeto é um esforço da comunidade para traduzir Dragon's Dogma Online e não é oficialmente endossado pela Capcom.
